# 改善の記録（improvement-log）

> AI の進め方のミスを記録し、同じミスが起きないように docs・ルール・仕組みへ反映するための記録。プロジェクトでは `docs/improvement-log.md` に置く。本番の障害は ai-ddd の `docs/templates/incident-record-template.md` を使い、この記録とは分ける。

## ミスが起きたときの手順

1. **止める**: ミスと分かった作業を止める。
2. **記録する**: 下の表に 1 件として書く。
3. **直す**: 成果物をその場で直したうえで、「直す場所」にも反映する。ai-ddd の親基盤に関わるものは、ai-ddd の `docs/feedback/` に記録する。
4. **同じ種類のミスが 2 回続いたら**: 修正を重ねずに作業を止め、現在地を `docs/progress-status.md` に書き、新しいセッションで docs から再開する。

止まる場所（A・B・C）では、この記録を見直し、反映していないものがないかを確かめる。

## 原因の種類

- ルールがなかった
- ルールを読んでいなかった
- 圧縮・再開・AI の切り替えで失われた
- 頼まれていない判断を先にした
- その他（具体的に書く）
